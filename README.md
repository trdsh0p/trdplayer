
# 🎵 Tried Player

A lightweight Spotify desktop client for Windows.

## ✨ Features
- Modern dark interface
- Minimalist design
- Spotify search
- Spotify embedded player
- Windows desktop application
- Lightweight Electron app

## 🖥️ Installation

Download the latest Windows installer from GitHub Actions Artifacts.

Run `Tried-Player-Setup.exe` and follow the installation instructions.

## 🛠️ Built With
- HTML
- CSS
- JavaScript
- Electron
- Node.js

## 🚀 Run Locally

```bash
git clone https://github.com/YOUR_USERNAME/tried-player.git
cd tried-player
npm install
npm start
```

## 📦 Build

```bash
npm run dist
```

The installer will appear in the `dist` folder.
